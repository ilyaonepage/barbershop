# СЕВЕР BARBERSHOP — демо-сайт

Статический одностраничный сайт (HTML/CSS/JS, без сборки).

## Публикация на GitHub Pages
1. Создайте репозиторий и загрузите содержимое папки (index.html в корне).
2. Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`.
3. Сайт появится по адресу `https://<логин>.github.io/<репозиторий>/`.

## Что заменить перед публикацией
Все данные — в объекте `CONFIG` в начале `js/main.js`: адрес, телефон, Telegram-ник (`telegram`), цены, часы, мастера.
Демо-плашка вверху — блок `.demo` в `index.html`. Иллюстрации в `images/` — заглушки: замените на реальные фото.

Запись: форма готовит сообщение и открывает Telegram; сервера нет.
